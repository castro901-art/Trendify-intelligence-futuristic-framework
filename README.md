# Tiff AI

Tiff AI — React frontend + Express backend chatbot with optional real-time web search support and OpenAI integration.

## Repo structure

- `client/` — React frontend
- `server/` — Express backend

## Features

- Chat UI with voice input (Web Speech API) + speech synthesis.
- Backend proxy to OpenAI for chat completions.
- Optional web search integration (SerpAPI or Bing) to provide near real-time info/responses.
- Designed for easy deployment (Netlify/Vercel for frontend, Render/Heroku/Vercel for backend).
